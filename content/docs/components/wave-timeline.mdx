## Features

- **Timeline ruler** — tick marks and time labels rendered above and/or below the waveform via the WaveSurfer Timeline plugin; fully themed via `useCssVar`.
- **Zoom** — three-way zoom control: step buttons (×1.5) and a precise slider, all calling `ws.zoom()` at runtime.
- **Seek bar** — a shadcn `Slider` synced to playback progress; click or drag the waveform directly thanks to `dragToSeek`.
- **Volume & mute** — slider-based volume with a mute toggle that preserves the last set level.
- **Loading state** — a spinner overlays the waveform while wave is being fetched and decoded.
- **Shadcn theming** — `waveColor` and `progressColor` accept any CSS value including `var(--*)` tokens, resolved at runtime for the Canvas API via `useCssVar`.

## API Reference

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `src` | `string` | — | **(Required)** Audio URL. Changing it recreates the wavesurfer instance. |
| `title` | `string` | — | Track title displayed above the waveform. |
| `defaultVolume` | `number` | `0.8` | Initial volume `0`–`1`. |
| `defaultZoom` | `number` | `50` | Initial zoom level in px/s. |
| `minZoom` | `number` | `10` | Minimum zoom level for the slider and buttons. |
| `maxZoom` | `number` | `500` | Maximum zoom level for the slider and buttons. |
| `topTimeline` | `TimelineOptions | false` | `{}` | Top ruler config. Pass `false` to hide. |
| `bottomTimeline` | `TimelineOptions | false` | `false` | Bottom ruler config. Pass `{}` or options to show. |
| `onPlay` | `() => void` | — | Fired when playback starts. |
| `onPause` | `() => void` | — | Fired when playback pauses. |
| `onFinish` | `() => void` | — | Fired when the track ends. |
| `onTimeUpdate` | `(currentTime: number, duration: number) => void` | — | Fired on every playback tick. |
| `waveColor` | `string` | `var(--muted-foreground)` | Waveform bar color. Accepts any CSS value including `var(--*)` tokens. |
| `progressColor` | `string` | `var(--primary)` | Progress overlay color. Same formats as `waveColor`. |
| `waveHeight` | `number` | `80` | Waveform canvas height in px. |
| `barWidth` | `number` | `2` | Bar width in px. |
| `barGap` | `number` | `1` | Gap between bars in px. |
| `barRadius` | `number` | `2` | Border radius of each bar. |
| `className` | `string` | — | Extra classes on the outer `<Card>`. |

### TimelineOptions

| Option | Type | Default (top) | Default (bottom) | Description |
| ------ | ---- | ------------- | ---------------- | ----------- |
| `height` | `number` | `20` | `14` | Height of the ruler in px. |
| `timeInterval` | `number` | `0.5` | `0.1` | Seconds between tick marks. |
| `primaryLabelInterval` | `number` | `5` | `1` | Seconds between primary labels. |
| `secondaryLabelInterval` | `number` | `1` | — | Seconds between secondary labels. |
| `fontSize` | `string` | `"11px"` | `"10px"` | CSS font size of the labels. |

Changing any timeline option recreates the wavesurfer instance, so treat these as configuration rather than live state.

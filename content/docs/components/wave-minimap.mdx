## Features

- **Overview Minimap** — a small overview of the full waveform to easily navigate.
- **Viewport Indicator** — highlights the currently zoomed visible area.
- **Zoom Controls** — perfectly paired with zoom so you can focus on details while keeping the full context.

## Usage

```tsx
import { WaveMinimap } from "@/components/waves-cn/wave-minimap"
```

```tsx
<WaveMinimap src="/coastline.mp3" />
```

## API Reference

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `src` | `string` | — | **(Required)** Audio URL. Changing it recreates the wavesurfer instance. |
| `title` | `string` | — | Track title displayed above the waveform. |
| `defaultVolume` | `number` | `0.8` | Initial volume `0`–`1`. |
| `minimapHeight` | `number` | `30` | Height of the overview strip in px. |
| `minimapWaveColor` | `string` | `var(--muted-foreground)` | Overview waveform color. Resolved from CSS variables for the canvas and follows theme changes. |
| `minimapProgressColor` | `string` | `var(--primary)` | Overview progress color. |
| `overlayColor` | `string` | `color-mix(in oklab, var(--primary) 15%, transparent)` | Viewport indicator color drawn over the overview. |
| `defaultZoom` | `number` | `100` | Initial zoom level of the main waveform in px/s. |
| `minZoom` | `number` | `10` | Minimum zoom level. |
| `maxZoom` | `number` | `500` | Maximum zoom level. |
| `onPlay` | `() => void` | — | Fired when playback starts. |
| `onPause` | `() => void` | — | Fired when playback pauses. |
| `onFinish` | `() => void` | — | Fired when the track ends. |
| `onTimeUpdate` | `(currentTime: number, duration: number) => void` | — | Fired on every playback tick. |
| `waveColor` | `string` | `var(--muted-foreground)` | Waveform bar color. Accepts any CSS value including `var(--*)` tokens. |
| `progressColor` | `string` | `var(--primary)` | Progress overlay color. Same formats as `waveColor`. |
| `waveHeight` | `number` | `80` | Waveform canvas height in px. |
| `barWidth` | `number` | `2` | Bar width in px. |
| `barGap` | `number` | `1` | Gap between bars in px. |
| `barRadius` | `number` | `2` | Border radius of each bar. |
| `className` | `string` | — | Extra classes on the outer `<Card>`. |

## Features

- **Overview Minimap** — a small overview of the full waveform to easily navigate.
- **Viewport Indicator** — highlights the currently zoomed visible area.
- **Zoom Controls** — perfectly paired with zoom so you can focus on details while keeping the full context.

## Usage

```tsx
import { WaveMinimap } from "@/components/waves-cn/wave-minimap"
```

```tsx
<WaveMinimap src="/coastline.mp3" />
```

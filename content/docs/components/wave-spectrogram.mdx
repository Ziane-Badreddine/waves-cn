## Features

- **Frequency Spectrogram** — renders a heat map of frequency (Y) over time (X).
- **Customizable Resolution** — adjust the FFT samples to control detail vs performance.
- **Labels** — optional frequency axis labels.

## Usage

```tsx
import { WaveSpectrogram } from "@/components/waves-cn/wave-spectrogram"
```

```tsx
<WaveSpectrogram src="/coastline.mp3" />
```

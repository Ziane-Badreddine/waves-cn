## Features

- **Interactive Regions** — allows creating regions by dragging on the waveform.
- **Resize & Move** — region handles allow modifying boundaries interactively.
- **Looping** — select a region and click the repeat button to loop play it.
- **Events** — fires callbacks when regions are created, updated, deleted, or clicked.

## Usage

```tsx
import { WaveRegions } from "@/components/waves-cn/wave-regions"
```

```tsx
<WaveRegions src="/coastline.mp3" />
```

## API Reference

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `src` | `string` | — | **(Required)** Audio URL. Changing it recreates the wavesurfer instance. |
| `title` | `string` | — | Track title displayed above the waveform. |
| `defaultVolume` | `number` | `0.8` | Initial volume `0`–`1`. |
| `editable` | `boolean` | `true` | Allow drag-selecting new regions and moving / resizing existing ones. |
| `regionColor` | `string` | `color-mix(in oklab, var(--primary) 25%, transparent)` | Fill color of regions. |
| `activeRegionColor` | `string` | `color-mix(in oklab, var(--primary) 45%, transparent)` | Fill color of the selected (loopable) region. |
| `onRegionCreated` | `(region: RegionData) => void` | — | Fired when the user creates a region. |
| `onRegionUpdated` | `(region: RegionData) => void` | — | Fired after a region is moved or resized. |
| `onRegionRemoved` | `(id: string) => void` | — | Fired when a region is removed. |
| `onRegionClicked` | `(region: RegionData) => void` | — | Fired when a region is clicked. The region becomes active. |
| `onPlay` | `() => void` | — | Fired when playback starts. |
| `onPause` | `() => void` | — | Fired when playback pauses. |
| `onFinish` | `() => void` | — | Fired when the track ends. |
| `onTimeUpdate` | `(currentTime: number, duration: number) => void` | — | Fired on every playback tick. |
| `waveColor` | `string` | `var(--muted-foreground)` | Waveform bar color. Accepts any CSS value including `var(--*)` tokens. |
| `progressColor` | `string` | `var(--primary)` | Progress overlay color. Same formats as `waveColor`. |
| `waveHeight` | `number` | `64` | Waveform canvas height in px. |
| `barWidth` | `number` | `3` | Bar width in px. |
| `barGap` | `number` | `2` | Gap between bars in px. |
| `barRadius` | `number` | `2` | Border radius of each bar. |
| `className` | `string` | — | Extra classes on the outer `<Card>`. |

### RegionData

| Field | Type | Description |
| ----- | ---- | ----------- |
| `id` | `string` | Stable id assigned by wavesurfer. |
| `start` | `number` | Start time in seconds. |
| `end` | `number` | End time in seconds. |
| `color` | `string` | Current fill color. |
| `content` | `string` | Text content, if any. |
